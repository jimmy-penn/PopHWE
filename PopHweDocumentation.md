# PopHWE Software Documentation

PopHWE performs HWE-test for genotype datasets in the presense of population structure. Currently it is implemented in Python. The test dataset is partitioned into relatively homogeneous ancestry groups. PopHWE uses the method decribed in Jin and Bao (2026) to calculate a chi-square value \$\\chi^{2}_{p}\$, which can be used to calculate the p-value under the null hypothesis that all the ancestry groups are in HWE. It also calculates other chi-square values including \$\\\\chi^{2}_{c}\$, \$\\chi^{2}_{e}\$, and \$\\\\chi^{2}_{d}\$, as described in the manuscript.


### Input files

PopHWE takes a text file with genotype counts for all variants and all ancestry groups, and calculates the chi-square values. For human genotype data, PopHWE can also take a genotype dataset in VCF format (`.vcf` or `.vcf.gz`) and partition the dataset in ancestry groups using GrafAnc and calculate the genotype counts. The usages of the scripts are described below using examples.


### Running `GetGenoCntsFromVcf.py` to calculate genotype counts by ancetry groups from a VCF file

Example (current directory is the `PopHWE`):

Instructions can be obtained by using `--help` option, e.g.,

``` sh
$ python GetGenoCntsFromVcf.py --help
usage: GetGenoCntsFromVcf.py [-h] [--use_sub_anc] [--num_mix_groups ] [--use_groups] [--merge_list ] vcf_file grafanc_file output_file

This script calculates variant allele frequencies by ancestry groups.

positional arguments:
  vcf_file           Vcf file with genotypes
  grafanc_file       Sample ancestry group file generated by GrafAnc or other programs
  output_file        The .png file to save the scatterplot

options:
  -h, --help         show this help message and exit
  --use_sub_anc      Use sub-continental ancestry groups
  --num_mix_groups   Further divide admixed groups into xx subgroups
  --use_groups       Current ancestry grouping is good, use it for HWE-test
  --merge_list       Two-column ancestry group merge list file, eash line like '303 301+302'
```


The following command summarizes the ancestry groups made by GrafAnc and shows the results on screen, letting the user to each merge the groups or take the ancestry grouping:

``` sh
$ mkdir results
$ python GetGenoCntsFromVcf.py medium_testing/input/TgpAncSnps1k.vcf.gz medium_testing/input/Tgp282k_pops.txt results/TgpAncSnps1kCnts.txt
```

When option `use_sub_anc` is set, the script splits the dataset into sub-continental ancestry groups:

``` sh
$ python GetGenoCntsFromVcf.py medium_testing/input/TgpAncSnps1k.vcf.gz medium_testing/input/Tgp282k_pops.txt results/TgpAncSnps1kCnts.txt --use_sub_anc
```

The sub-continental ancestry groups includes admixed populations such as Latin Americans and African Americans. These sub-populations may also have population structure. Option `num_mix_groups` can be used to further split these admixed populations into specified number of groups:

``` sh
$ python GetGenoCntsFromVcf.py medium_testing/input/TgpAncSnps1k.vcf.gz medium_testing/input/Tgp282k_pops.txt results/TgpAncSnps1kCnts.txt --num_mix_groups 5
```

In case it is necessary to merge some groups, the user can create a merge list file and let the script merge some groups:

``` sh
$ python GetGenoCntsFromVcf.py medium_testing/input/TgpAncSnps1k.vcf.gz medium_testing/input/Tgp282k_pops.txt results/TgpAncSnps1kCnts.txt --num_mix_groups 5 --merge_list medium_testing/input/MergeList01.txt
```

If the grouping looks good, the user can use `--use_groups` to accept it:

``` sh
$ Python/bin/python GetGenoCntsFromVcf.py medium_testing/input/TgpAncSnps1k.vcf.gz medium_testing/input/Tgp282k_pops.txt results/TgpAncSnps1kMrg10Cnts.txt --num_mix_groups 5 --merge_list medium_testing//input/MergeList01.txt --use_groups
```
